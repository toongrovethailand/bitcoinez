โซ่ทองแห่งความจริง (The Magic of Hash)

ลองแก้ไขข้อความในบล็อกที่ 1 แล้วสังเกตดูว่ารหัส Hash สีทอง (ตัวอักษร 64 ตัว) เปลี่ยนแปลงไปอย่างไร และมันส่งผลกระทบต่อเนื่องเป็นโดมิโนไปยังบล็อกอื่นๆ อย่างไรบ้าง

💡 สิ่งที่คุณเพิ่งได้เรียนรู้ไป (Avalanche Effect)

คุณจะเห็นว่าการเปลี่ยนแปลงข้อความแม้เพียงตัวอักษรเดียวใน Block #1 จะส่งผลให้ Hash ของ Block #1 เปลี่ยนไปเป็นคนละค่าโดยสิ้นเชิง

เมื่อ Hash ของ Block #1 เปลี่ยน ➔ มันก็จะทำให้ค่า Prev Hash ของ Block #2 เปลี่ยนตาม ➔ ส่งผลให้สมการรวมของ Block #2 เปลี่ยน ➔ ทำให้ Hash ของ Block #2 เปลี่ยนไปอีกที ➔ และสะเทือนไปถึง Block ถัดๆ ไปเรื่อยๆ อย่างไม่มีที่สิ้นสุด!

The Power of Blockchain นี่คือเหตุผลที่ว่าทำไม แฮกเกอร์ถึงไม่สามารถย้อนกลับไปแก้ไขข้อมูลการโอนเงินในอดีตได้ เพราะถ้าพวกเขาแอบแก้ข้อมูลในบล็อกเก่า พวกเขาจะต้องมานั่งคำนวณรหัส Hash ของบล็อกที่เหลือใหม่ทั้งหมดให้ทันก่อนที่คนอื่นๆ จะจับได้ ซึ่งเป็นเรื่องที่เป็นไปไม่ได้เลยในทางคณิตศาสตร์!
